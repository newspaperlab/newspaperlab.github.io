쿠키와 브라우저 저장소 안내

무엇이 저장되는지 알고, 직접 관리하세요.

시행일 2026.11.06 · 버전 2026-11-06.1

안내를 닫는 것은 광고 동의가 아닙니다. 저장되는 항목은 안내 확인 상태, 정책 버전, 만료 시각뿐입니다.

현재 사용하는 항목직접 확인하고 삭제하기브라우저에서 관리하기향후 광고·분석을 도입할 때

현재 사용하는 항목

이 페이지의 ‘쿠키’ 안내에는 브라우저 로컬 저장소 같은 유사 기술도 포함합니다. 현재 운영자가 직접 사용하는 것은 아래 안내 확인 항목 한 개이며, 광고·방문 분석용 쿠키는 설정하지 않습니다.

항목위치·목적보관 및 전송
nl_privacy_notice_v1브라우저 localStorage. 안내 확인 여부, 방침 버전, 만료 시각만 저장합니다.최대 180일. 서버 전송 없음. 같은 도메인의 메인·에어로그·일렉트로뉴스가 공유합니다.
광고·맞춤 광고사용하지 않습니다.현재 해당 스크립트·쿠키 없음.
방문 분석·통계 추적사용하지 않습니다.현재 해당 스크립트·쿠키 없음.
언어·기사 검색언어는 URL, 검색은 현재 페이지에서 처리합니다.별도 쿠키나 검색 이력을 저장하지 않습니다.

브라우저 캐시는 페이지를 빠르게 불러오기 위해 브라우저가 관리하는 사본이며, 이 안내 확인 항목과 다릅니다. 호스팅 제공자의 보안 로그도 브라우저 설정 기록과 별개입니다. 자세한 범위는 개인정보처리방침을 확인하세요.

직접 확인하고 삭제하기

설정 화면에서 저장 여부와 만료일을 확인하고 ‘안내 확인 기록 삭제’를 누를 수 있습니다. 삭제하면 이 도메인의 다른 매체에서도 다음 방문 시 안내가 다시 보일 수 있습니다. 브라우저의 다른 데이터나 외부 서비스의 쿠키를 일괄 삭제하지는 않습니다.

‘확인하고 닫기’는 안내를 보았다는 기록만 저장합니다. 광고나 방문 분석에 동의하는 버튼이 아닙니다. 버튼을 누르지 않아도 기사를 읽을 수 있습니다. 저장이 차단되면 해당 페이지에서만 창을 닫으며, 다음 방문에서 다시 보일 수 있습니다.

브라우저에서 관리하기

브라우저의 설정에서 newspaperlab.github.io를 찾아 사이트 데이터를 지우거나 저장을 제한할 수 있습니다. 메뉴 이름은 버전과 운영체제에 따라 달라질 수 있습니다.

  • Chrome: 설정 → 개인정보 보호 및 보안 → 사이트 설정 또는 사이트 데이터 관리
  • Edge: 설정 → 쿠키 및 사이트 권한 또는 개인정보 관련 사이트 데이터 설정
  • Safari: 설정 → 개인정보 보호 → 웹 사이트 데이터 관리
  • Firefox: 설정 → 개인정보 및 보안 → 쿠키와 사이트 데이터 → 데이터 관리

서드 파티 쿠키 차단만으로 localStorage가 항상 삭제되는 것은 아닙니다. 이 안내의 기록을 지우려면 해당 사이트의 저장된 데이터도 확인하세요. 공용 기기에서는 브라우저 전체 기록을 지우기 전에 다른 이용자의 데이터가 포함돼 있는지도 살펴보세요.

향후 광고·분석을 도입할 때

새로운 도구가 도입되면 도구명, 목적, 수집 정보, 보관 및 선택 방법을 사용 전에 갱신합니다. 필요한 동의 없이 선택형 추적을 실행하는 방식으로 이 확인 기록을 재사용하지 않습니다.

Google 광고의 데이터 이용 방식과 맞춤 광고 제어는 Google 파트너 사이트 안내, 내 광고 센터에서 확인할 수 있습니다. 외부 설정은 이 사이트의 확인 기록 삭제와 서로 다른 기능입니다.
