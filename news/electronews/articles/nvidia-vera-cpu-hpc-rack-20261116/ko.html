NVIDIA, Vera CPU 192개 묶은 과학 컴퓨팅 랙 공개

전체 랙은 2027년 초부터 공급사 제품으로 나올 예정이에요. SDK와 포트란 컴파일러 공개 베타는 먼저 시작됐어요.

Newspaper Lab 편집 · 게시 2026-11-17 07:00 KST
원문 발표 2026-11-16

데이터센터 소식을 볼 때 CPU 하나의 속도만 보면 전체 그림을 놓치기 쉬워요. NVIDIA는 11월 16일 미국 SC26에서 Vera CPU 192개를 하나의 액체 냉각 랙으로 묶은 고성능컴퓨팅 플랫폼을 공개했어요. 기후·분자 시뮬레이션처럼 큰 데이터를 계속 옮기는 작업을 겨냥했고, Dell·HPE·Lenovo·Supermicro가 2027년 초부터 랙 제품을 공급할 예정이에요.

랙은 1U 트레이마다 Vera CPU 8개를 넣고, 전체 192개를 Quantum-X800 InfiniBand로 연결해요. NVIDIA가 공개한 구성은 약 300TB 메모리와 1PB 저장장치, 전체 합산 최대 메모리 대역폭 200TB/s 이상이에요. 이 숫자는 랙 전체 자원을 합친 값이지, CPU 하나나 단일 프로그램이 항상 그대로 쓰는 속도가 아니에요.

각 Vera CPU는 NVIDIA가 설계한 Olympus 코어 88개와 176스레드, 최대 1.2TB/s 대역폭의 SOCAMM2 LPDDR5X 메모리를 사용해요. 그래픽카드를 중심으로 알려진 NVIDIA가 CPU만으로 돌아가는 과학 계산과 메모리 집약 작업까지 플랫폼 범위를 넓히는 흐름이에요. SHARP 인네트워크 컴퓨팅은 여러 노드가 결과를 합치는 통신 부담을 네트워크 쪽에서 일부 처리해요.

NVIDIA는 OpenFOAM motorBike Large 유동 시뮬레이션에서 x86 시스템 대비 성능 1.9배, 전력당 성능 2.4배를 측정했다고 밝혔어요. 기상 연구용 WRF 모델에는 성능 1.6배, 에너지 효율 2배를 예상했어요. 모두 NVIDIA의 시험과 예상치이며, 비교 시스템 구성과 소프트웨어 최적화가 결과에 영향을 줘요. 다른 연구 코드에서도 같은 배수가 나온다고 단정하면 안 돼요.

독일 기후컴퓨팅센터 DKRZ는 2028년 초 가동 예정인 HLRE-5 슈퍼컴퓨터에 Vera CPU를 선택했어요. GB200 Grace Blackwell 시스템과 Quantum-2 네트워크도 함께 쓰는 혼합 구성이에요. 따라서 Vera 랙이 기존 CPU 서버를 모든 작업에서 단독으로 대체한다기보다, 시뮬레이션과 AI를 섞는 시스템의 한 부분으로 들어간다고 보는 편이 맞아요.

하드웨어 판매 전에도 개발자는 먼저 준비할 수 있어요. NVIDIA HPC SDK 26.11은 지금 제공되고, Vera에 맞춘 컴파일러와 라이브러리를 포함해요. 차세대 포트란 컴파일러 공개 베타도 시작했어요. 오래된 과학 코드를 완전히 다시 쓰지 않고 새 플랫폼에서 시험하려는 연구기관에 중요한 단계예요.

가격, 실제 공급 수량, 기관별 전력·냉각 요구사항은 이번 발표에 모두 나오지 않았어요. 2027년 초라는 시점도 개별 제조사 제품의 정확한 출하일과 같지 않아요. 도입을 검토한다면 NVIDIA의 벤치마크 세부 구성과 자신의 코드·데이터 크기를 맞춰 검증하고, 랙 전력과 냉각 공사까지 포함한 총비용을 계산해야 해요.

이 수치를 일반 PC 성능표처럼 받아들이면 안 돼요. OpenFOAM과 WRF는 유체역학·기상 계산에 쓰이는 특정 작업이고, 결과는 문제 크기·컴파일러·메모리 배치에 따라 달라져요. NVIDIA가 공개한 비교는 공급사 시험과 전망치이므로 실제 연구기관의 조달 검증 결과와 구분해야 해요. 랙 도입에는 전력·냉각·네트워크·소프트웨어 이전 비용도 따라오는데, 이번 발표에는 가격과 총소유비용이 공개되지 않았어요. 기관별 실측 자료가 나와야 경제성을 판단할 수 있어요.
